## why there is no a5-no-timeout arm

`timeout` is a GNU coreutils binary and this platform (macOS/BSD userland) does not
provide it: it is absent from every directory the controlled bin dir was built from, so
there is nothing to remove. The harness attempted the arm, could not plant the removal,
and HARNESS-ABORTED with "cannot plant: 'timeout' is not in the controlled bin dir"
rather than silently producing a case that removed nothing and looked like a planted
failure. The aborted case directory was removed rather than published.

The observation the arm would have produced is already in the CLEAN arm: with the full
controlled bin dir in place, the doctor checklist still reports its `timeout` line,
because the tool is genuinely missing on this platform. See
`a5-clean-controlled-path/checklist.txt`.

This is recorded rather than worked around: an arm that cannot be built on the platform
under test is a fact about the platform, and inventing a stand-in binary to remove would
have measured the stand-in.
